# COMPREHENSIVE INDEXING MANDATE
Sebelum melakukan query graph, WAJIB memanggil:

Required MCP calls (in order). For each, save raw JSON to `raw/graph/<slug>.json`:

```
1. get_graph_schema(project=<name>)           → schema.json
2. get_architecture(project=<name>)           → architecture.json
3. query_graph(project, cypher=fan-in-query)  → fan-in.json
4. query_graph(project, cypher=co-change-query)→ co-change.json
5. query_graph(project, cypher=dead-code-query)→ dead-code.json
6. query_graph(project, cypher=cycles-query)  → cycles.json
7. trace_path(entrypoint_qualified_name, depth=3)
   for each entry point found in architecture.json
                                              → trace-<name>.json
```

Sample Cypher queries (adapt to schema from step 1):

```cypher
// fan-in
MATCH (n)<-[:USAGE|CALLS]-()
RETURN n.qualified_name AS name, count(*) AS fan_in
ORDER BY fan_in DESC LIMIT 30;

// co-change
MATCH (a)-[r:FILE_CHANGES_WITH]->(b)
RETURN a.path AS a_path, b.path AS b_path, r.count AS changes, r.score AS score
ORDER BY r.score DESC LIMIT 30;

// dead code
MATCH (n:Class|Method|Function)
WHERE NOT ()-[:USAGE|CALLS]->(n)
RETURN n.qualified_name AS qn, n.path AS path
LIMIT 20;

// cycles
MATCH path=(a)-[:IMPORTS*2..8]->(a)
RETURN [n IN nodes(path) | n.path] AS cycle LIMIT 10;
```

If a query errors (schema mismatch), record the error to `raw/graph/query-errors.log`
and continue with the remaining queries.

Update checkpoint.

On failure: graph project not registered and `index_repository` fails → record `MCP_UNAVAILABLE`, continue to Phase 4 with E1-only.

Agent: `reviewer` (delegated). Task: collect all findings across categories.

DEDUPLICATION: Sebelum membuat report audit baru, baca semua file `0ai_context/reports/*-fix-*.md`. Jika sebuah AUDIT-ID sudah ada di dalam file fix tersebut, HAPUS temuan itu dari daftar audit baru (karena sudah RESOLVED).

- Pattern scans (bash grep, language-adapted)
- Graph signals (fan-in > 10, dead code, cycles)

Pattern scan commands (run in repo root):

```bash
# Defect markers
grep -rnE '\b(TODO|FIXME|HACK|BUG|XXX)\b' <src-dirs>/ 2>/dev/null

# Empty error handlers (language-adapted)
# Dart/Java/Kotlin:
grep -rnE 'catch\s*\([^)]*\)\s*\{\s*\}' <src>/ 2>/dev/null
# Python:
grep -rnE 'except\s*:\s*pass' <src>/ 2>/dev/null
# Go:
grep -rnE 'if err != nil \{\s*\}' <src>/ 2>/dev/null
# Rust:
grep -rnE '\.unwrap\(\)|\.expect\(' <src>/ 2>/dev/null
# JS/TS:
grep -rnE 'catch\s*\([^)]*\)\s*\{\s*\}' <src>/ 2>/dev/null

# Potential secrets (record path:line only, redact value)
grep -rnE '(api[_-]?key|secret|password|token)\s*[:=]\s*["'\''][^"'\'']{8,}' <src>/ 2>/dev/null

# Hardcoded paths
grep -rnE '["'\'']/(home|Users|root|storage)/' <src>/ 2>/dev/null

# Files > 400 LOC
git ls-files '<src-dirs>/**' | xargs wc -l 2>/dev/null | awk '$1>400 && $2!="total"'
```

Classify each finding:

| Severity | Definition |
|----------|-----------|
| P0 | Data loss, security vulnerability, privacy leak, crash |
| P1 | Incorrect behavior, race, broken build/test, unchecked error handler in critical path |
| P2 | Performance anti-pattern, coupling debt, missing cleanup, unused code |
| P3 | Style, docs drift, TODO/FIXME marker, minor quality |

| Category | Examples |
|----------|----------|
| correctness | Unhandled error, off-by-one, wrong cast |
| safety | Path traversal, shell injection, secret in source |
| performance | O(n²) hot loop, sync I/O on UI thread |
| lifecycle | Resource leak, listener not removed |
| quality | Over-length file, dead code, cycle |
| documentation | Stale claim in README/ARCH, missing docstring |

Each finding must have: `id` (AUDIT-YYYYMMDD-NNN), `severity`, `category`,
`location`, `impact` (1 sentence), `fix` (1 sentence), `scope`, `since`.

Location format rules:
- Single line: `<path>:<line>` — e.g. `lib/core/services/ffmpeg_service.dart:149`
- Single file, whole file: `<path>:1`
- Directory-wide: `<dir>/ (<N> files)` — e.g. `lib/ (89 files)`
- Multi-file specific: comma-separated paths, max 3
- NEVER write `<dir>/:1` — that is ambiguous

The rendered `location` field goes into HANDOFF.md §10 and 98-audit.md
`Location` column verbatim.

Cap at 25 findings by severity then by fan-in of affected symbol.

Save to `raw/findings.json`.

Update checkpoint.

On failure: all pattern scans fail (no src dirs detected) → record `SCAN_EMPTY` and continue.
